# 🛒 Shop App (React + Redux + Stripe)

A modern e-commerce frontend built with **React**, **Redux**, and **Tailwind CSS**.  
The app features **product categories**, **product listing pages**, and a **Stripe test payment integration**.

### Live URL: https://grocery-3tr1.onrender.com/

---

## 🚀 Features

- Browse products by categories
- View product details and pages
- Redux state management for cart and products
- Stripe test payment integration
- Responsive layout with Tailwind CSS
- Routing with React Router v6

---

## 🛠 Tech Stack

- **React 18**
- **Redux Toolkit**
- **React Router DOM**
- **Tailwind CSS**
- **Heroicons**
- **Stripe (frontend & test payments)**
- **Helmet**

---

## 💳 Payment Integration

- Test payments powered by **Stripe**
- Uses **Stripe.js** to securely handle card inputs
- Demo mode only — no real payments processed
